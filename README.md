# Termo-em-C++
Criei um jogo similar ao Termo em C++.
* Seu objetivo é descobrir a palavra secreta em 6 tentativas.
* Você pode chutar palavras para descobrir as letras certas, erradas e suas posições antes que suas chances acabem! Divirta-se!

# Compilação e execução
Para compilar e executar o programa rode em seu terminal o seguinte código:
```
g++ "NOME_DO_ARQUIVO".cpp -o "NOME_DO_EXECUTAVEL"
./"NOME_DO_EXECUTAVEL"
```

# Créditos
O jogo foi totalmente inspirado no site: https://term.ooo/

# Observações
Caso você esteja no Windows, é possivel que o comando ```system(clear);``` não funcione.
Nesse caso, substitua-o por ```system(cls);``` no código.
